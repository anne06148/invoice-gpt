# 🧾 Invoice GPT

מעלים חשבוניות ספקים (תמונות או PDF, הרבה בבת אחת), Claude מחלץ את הכותרת ואת שורות הפריטים, האפליקציה בודקת את הנתונים, ובסוף מורידים אקסל מוכן לקליטה ב-Priority.

## מה יש
- **חילוץ עם Claude Vision** ופלט מובנה: סוג מסמך, ספק, ח.פ., מספר חשבונית, תאריכים, מספר הקצאה, מטבע, לפני מע"מ, מע"מ, סה"כ ושורות פריטים.
- **בדיקות אוטומטיות**: ספרת ביקורת של ח.פ., כמות × מחיר = סה"כ שורה, סכום השורות = לפני מע"מ, לפני מע"מ + מע"מ = סה"כ, אחוז מע"מ, שדות חסרים, וחשבוניות כפולות.
- **עריכה בטבלה**: מתקנים תא והבדיקות מתעדכנות מיד.
- **ייצוא לאקסל (RTL)** עם שלושה גיליונות: כותרות (כולל סטטוס והערות), שורות, וסיכום לפי ספק.
- **מצב דמו**: כפתור "טען חשבוניות לדוגמה" עובד גם בלי API key.

## הרצה
```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...   # או להדביק בסרגל הצד
streamlit run app.py
```
